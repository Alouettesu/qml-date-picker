# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-13

### Added
- Initial release of QML Date Picker Demo
- DatePicker component with year, month, and day selection
- YearPicker component with configurable range
- MonthPicker component with range constraints
- DayPicker component with automatic month length adjustment
- Locale support for month names
- Date range validation
- Smooth scrolling animations
- Demo application showcasing all components
- Comprehensive documentation and examples
- GitHub Actions CI/CD workflow
- MIT License

### Features
- Mobile-style scrollable date picker interface
- Support for custom date ranges
- Automatic validation of date selections
- Responsive design
- Qt 6.x compatibility
